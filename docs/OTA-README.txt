Настройка OTA (обновления по воздуху)
=====================================

ВАЖНО: следующая сборка должна быть ОДНА и включать всё нативное.
После неё правки экранов и логики — через eas update (без новой сборки).

1. Положите файлы в корень проекта:
   - app.json
   - package.json (или вручную добавьте в dependencies: "expo-updates": "~57.0.0")
   - eas.json

2. Установите:
   npx expo install expo-updates

3. Убедитесь, что модель Vosk лежит здесь:
   assets/vosk-model-small-ru-0.22/
   (папка с файлами модели)

4. Соберите ОДИН раз:
   eas build --platform android --profile preview

5. После установки APK публикуйте JS-обновления:
   eas update --branch preview --message "описание"

Что требует новой сборки (нельзя по воздуху):
- react-native-vosk и модель
- любые новые нативные модули
- изменение permissions / app.json plugins

Что можно обновлять по воздуху:
- экраны, стили, логика парсера, тексты, онбординг и т.д.
